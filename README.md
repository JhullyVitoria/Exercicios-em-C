# Lógica de Programação em C

Este repositório contém o material de apoio e os exercícios práticos que desenvolvi para ensinar Lógica de Programação e Linguagem C em sala de aula. 

O objetivo deste projeto é unir a **teoria** com a **prática**, servindo como um guia passo a passo para alunos que estão tendo seu primeiro contato com a programação.

## Estrutura do Conteúdo

O repositório está organizado de forma evolutiva:

*   **`Var-Constantes/`**: Declaração de variáveis, tipos de dados e funções de entrada/saída (`printf` e `scanf`).
*   **`Operadores_Aritmeticos/`**: Operações matemáticas fundamentais aplicadas ao código junto de operadores lógicos.
*   **`Estruturas_Decisao/`**: Lógica condicional e desvios de fluxo (`if`, `else`, `switch`).
*   **`Estruturas de Repeticao/`**: Laços de repetição (`for`, `while`), incluindo teoria em PDF e algoritmos clássicos (validação de senha, números primos, médias).
*   **`Vetores-Matrizes/`**: Introdução a estruturas de dados unidimensionais e bidimensionais.

## Conteúdo das Pastas

Dentro das pastas de cada módulo, você encontrará:
1. **Material Teórico:** Arquivos `.pdf` com a explicação didática dos conceitos.
2. **Exercícios Resolvidos:** Arquivos `.c` contendo o enunciado do problema abordado em aula e a respectiva solução comentada em código.
